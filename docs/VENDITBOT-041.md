# 벤디트봇 0.4.1 — 앱 연결 개선

앱 연결 화면을 서비스 목록과 연결 버튼 중심으로 정리합니다. 별도 체크박스 대신 사용자가 연결 버튼을 누르면 공식 제공자의 로그인·권한 승인 화면으로 이동합니다. 공급자 등록이 준비되지 않은 항목은 연결 준비 중으로 표시하며, 작동하지 않는 연결 버튼을 노출하지 않습니다.

- 연결 단계, 취소, 실패 이유, 재시도를 표시합니다. 인증 연결과 실제 API 읽기 검사는 구분합니다.
- 관리자 등록 입력은 고급 설정으로 접고, 전용 공개 클라이언트 ID를 배포에 포함할 수 있습니다. 개인 토큰·클라이언트 시크릿은 배포 파일에 넣지 않습니다.
- GitHub 기기 로그인을 지원합니다. 공개 클라이언트 ID만으로 기기 승인과 토큰 갱신을 진행합니다.
- 로그인 응답을 브라우저에 전달하기 전에 소켓을 닫던 문제를 수정합니다. 완료 안내는 보안 헤더를 유지한 정적 HTML로 제공하며, 인증 코드나 상태 값을 화면에 표시하지 않습니다.
- Notion의 현재 사용자 조회 도구는 공식 서버가 실제 제공하는 경우에만 허용합니다.
- 화면 파일이 비어 있거나 복사 중 손상되면 빌드와 패키징을 중단해, 화면이 뜨지 않는 설치본의 생성을 차단합니다.

배포용 연결은 `VenditBot Desktop` 전용 앱을 사용합니다. Google 등록은 `vendit.co.kr` 조직 내부 계정용이며, Gmail·Calendar·Drive·Docs·Sheets를 서비스별 읽기 권한으로 연결합니다. Slack 등록은 VENDIT 작업공간의 공개 채널 읽기용입니다. GitHub 등록은 승인된 두 저장소(`vendit-rabbit`, `grok-bot-0.18-reconstructed`)의 코드·이슈·PR·메타데이터 읽기용입니다. 사용자에게 개발자 콘솔 등록을 요구하지 않으며, 다른 조직·작업공간·저장소를 추가하려면 해당 서비스에서 접근 범위를 별도로 승인해야 합니다.

GitHub·Slack의 공개 등록값은 앱에 포함합니다. 이 Google Desktop 등록은 실제 토큰 교환에서 앱 보안값을 요구하므로, Google 등록값은 설치할 Mac의 암호화 저장소에 한 번 설정합니다. 설정이 끝난 Mac에서는 일반 연결 버튼을 사용하며, 업데이트할 때도 이 설정을 보존합니다. Google 보안값은 소스·ZIP·로그·내보내기에 넣지 않습니다. 다른 Mac에 ZIP만 복사한 경우에는 Google의 로컬 설정이 아직 없으므로 준비되지 않은 상태로 표시합니다.

기존 계정, 에이전트, 팀, 대화, 루틴, 연결 정보는 유지합니다. 실제 계정 연결과 공급자 등록 여부는 릴리스 검증 기록에서 별도로 확인합니다. 자동 테스트의 합성 응답은 실제 계정 인증 성공을 의미하지 않습니다.
